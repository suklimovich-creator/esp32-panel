# esp32-panel

Своя прошивка настенного экрана для умного дома на Wiren Board.
Плитки и анимации рисуются на самом экране, данные идут напрямую из MQTT,
раскладка будет приходить с [wb-svg-panel](https://github.com/suklimovich-creator/wb-svg-panel)
(с версии 0.3).

**Железо:** Guition ESP32-4848S040 — ESP32-S3-N16R8 (16 МБ flash, 8 МБ PSRAM),
4" IPS 480×480 на ST7701S по RGB, тач GT911.
**Основа:** ESP-IDF 5.5, LVGL 9.2.
**Версия:** 0.11.3 — ТВ-пульт с приложениями слева и зубчатым колесом WB, компактный прогноз без наложений, подписанная плитка протечек; 0.11.2 — сцены сеткой 3×3, полноценный прогноз на плитке и полном экране, ТВ без наложения кнопок, протечки одной строкой, цвета CO₂/VOC как в wb-svg-panel; 0.11.1 — пульт света как у панели, «Сегодня» с переносом и прокруткой, первые версии новых пультов; 0.11.0 — плитки и пульты телевизора, протечек, погоды, дел и наборов сцен, пульт света с теплотой, заставка; камеры wb-svg-panel, настраиваемая сетка плиток, графики истории, тема graphite, раскладка с wb-svg-panel, данные из MQTT, настройка Wi-Fi, обновление по воздуху с откатом.
Изменения — в [CHANGELOG.md](CHANGELOG.md), план — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Что умеет

- Вывод на матрицу без разрывов: два кадра в PSRAM, LVGL рисует только изменённое.
- Подсветка включается после первого готового кадра (без «заливки сверху вниз»),
  через минуту без касаний приглушается.
- Первый запуск или Wi-Fi не найден за минуту — экран поднимает свою точку доступа
  `Panel-XXXX` и показывает её пароль и QR-код. Телефон, подключившись,
  сам открывает страницу настройки (или откройте `http://192.168.4.1`).
- Веб-страница экрана (`http://<адрес экрана>/`): состояние, Wi-Fi, адреса сервера
  прошивок и брокера, загрузка прошивки файлом, перезагрузка.
- Обновление с сервера: при старте (через минуту), раз в час и по кнопке.
  Ставится только версия новее текущей и только файл этой прошивки.
- Откат: новая версия должна за 2 минуты показать кадры на экране и подключиться
  к Wi-Fi, иначе загрузчик вернёт прошлую.
- Главный экран — вкладки страниц, часы и значок связи в одну строку, плитки
  сеткой с настраиваемым числом колонок. Значения приходят из MQTT напрямую
  от брокера, команды уходят в `…/on`.
- Графики `chart` — до трёх кривых в плитке; нажатие открывает полноэкранный
  график со шкалой и временем. Текущие значения приходят из MQTT, история —
  из wb-svg-panel 1.73+ по HTTP и обновляется раз в минуту.
- Камеры `camera` — JPEG в плитке и просмотр 480×480 по нажатию. Нужен
  wb-svg-panel 1.75+: экран обращается только к нему, без прямого подключения
  к камере и без её учётных данных в настройках прошивки.
- Плитки и пульты (wb-svg-panel 1.77+): телевизор `tv` с зубчатым колесом,
  громкостью и вертикальным рядом приложений слева; протечки `leak` со списком
  датчиков, названием плитки и сбросом защиты; погода `weather` с почасовым
  графиком; дела и события `today` из ленты; набор сцен `scenes` одной плиткой.
  Для автоматических цветов CO₂/VOC в раскладке нужен wb-svg-panel 1.77.1+.
- Пульт света: долгое нажатие на диммер открывает полноэкранные яркость
  и цветовую температуру.
- Заставка: секции панели со свойством `screensaver` образуют экран-заставку
  с часами; включается после бездействия, страницы листаются сами, касание
  будит экран. Открытые пульт и график перед заставкой закрываются сами.
- Значок Wi-Fi: красный — нет сети, жёлтый — нет брокера, белый — всё в порядке.
- Экран «Устройство» (шестерёнка): версия, Wi-Fi и число его обрывов с причиной,
  MQTT, раскладка, память, яркость, обновление, точка доступа, перезагрузка.
- Связь с роутером проверяется раз в 20 секунд; если он минуту не отвечает,
  экран переподключается к Wi-Fi сам.

## Раскладка панели

JSON со страницами и плитками. Откуда экран её берёт, по старшинству:

1. **Загруженная вручную** на веб-странице экрана (раздел «Раскладка панели»).
   Пока она есть, сервер не используется; «Удалить загруженную» возвращает к нему.
2. **С wb-svg-panel** (1.70+): `<сервер панели>/api/screen/<имя экрана>`,
   по умолчанию `http://192.168.1.77/panel/api/screen/panel-XXXX`. Экран
   проверяет её при старте и раз в минуту, копию хранит во flash; изменилась —
   перезапускается с новой. На сервере экран описывается разделом
   `screens:` и обычной панелью в `config.yaml` (см. docs панели, «Настенный экран»).
3. **Встроенная** — `main/layout_default.json`.

Адрес сервера панели меняется на веб-странице экрана; пустой — не брать.

```json
{ "cols": 3, "pages": [ { "title": "Гостиная", "tiles": [ … ] } ] }
```

| Тип | Поля | Что делает |
|---|---|---|
| `switch` | `state`, `cmd`* | нажатие включает и выключает |
| `dimmer` | `level`, `state`*, `temp`*, `max`* (100), `temp_min`*/`temp_max`* (0/100) | нажатие по шапке — вкл/выкл, ползунок — яркость, второй ползунок — цветовая температура |
| `scene` | `cmd`, `payload`* ("1") | отправляет команду |
| `sensor` | `value`, `unit`*, `digits`* (1) | показывает значение |
| `chart` | `range`, `points`, `history`, `series` (до 3: `value`, `unit`, `digits`, `color`, `label`, `min`/`max`*) | рисует историю в плитке, по нажатию — во весь экран (с 0.7) |
| `camera` | `snapshot`, `stream`* | JPEG в плитке; по нажатию MJPEG во весь экран, а без `stream` — снимки (с 0.11) |
| `info` | `value`*, `unit`*, `digits`*, `map`*, `lines`* (до 3: `label`, `topic`, `unit`, `digits`, `map`), `active`*, `note`* | сводка — кондиционер, термостат, шторы, график: значение крупно и строка подробностей; рамка подсвечена, когда `active` включён |
| ↳ `pad` (`style`: `ac`/`dial`, ещё `state`, `states`, `swing`, `swing_h` с `_cmd`) | `kind`: `climate` — `target`, `target_cmd`, `current`, `min`, `max`, `step`, `power`, `power_cmd`, `on`, `off`, `mode`, `mode_cmd`, `modes` (`[значение, подпись, cool/heat]`), `fan`, `fan_cmd`, `fans`, `tone`; `cover` — `pos`, `pos_cmd`, `style` (`curtain`/`roller`), `invert`, `open`, `close`, `stop_cmd`, `stop` | пульт во весь экран по нажатию на сводку (с 0.4) |
| `scenes` | `items` (до 12: `title`, `cmd`, `payload`*, `level`* 0–1, `icon`*) | набор сцен одной плиткой, нажатие на клавишу отправляет команду (с 0.11) |
| `tv` | `state`, `link`, `app`, `mode`, `states`, `pad` (`kind`: `tv` — `base`, `apps`: `title`, `cmd`) | телевизор: плитка со статусом, пульт с крестовиной и приложениями; клавиши — `<base><имя>/on` (с 0.11) |
| `leak` | `sensors` (`topic`, `title`), `alarm`*, `pad` (`kind`: `leak` — `reset`) | протечки: плитка со сводкой, пульт со списком датчиков и сбросом (с 0.11) |
| `weather` | `temp`, `desc`, `hum`, `press`, `wind`, `tmin`, `tmax`, `series` (`temp`, `code`, `prob`, `cloud`, `start`) | погода: на плитке и полноэкранно — почасовой прогноз с температурой, облачностью и осадками (с 0.11) |
| `today` | `data`, `list`* | «Сегодня»: дела и события из ленты по адресу `data` (с 0.11) |

У диммера с полем `pad` (`kind`: `light` — `state`, `level`, `temp` с `_cmd`,
`max`, `temp_min`/`temp_max`, `unit`, `cold`, `warm`) долгое нажатие на
плитке открывает полноэкранный пульт света (с 0.11).

Заставка (с 0.11): корневой блок `screensaver` — `{"after": секунды,
"every": секунды, "cols": колонки, "pages": [...]}`. Сервер панели заполняет
его сам из секций со свойством `screensaver`.

Корневое `cols` задаёт число колонок (2–5, по умолчанию 3). У всех плиток
есть `title`, `w` — ширина в колонках от 0,5 до `cols` и `h` — высота
в рядах от 0,5 до 2; оба размера принимают значения с шагом 0,5. Диммер по умолчанию
занимает всю ширину строки, остальные плитки — одну колонку. Если `cols`,
`w` или `h` не указаны, сохраняется прежняя трёхколоночная раскладка.
Название страницы (`title` у страницы) — надпись на вкладке. Звёздочкой отмечены необязательные поля. Команда по умолчанию —
топик значения с `/on` на конце, как принято в Wiren Board; явные адреса —
`state_cmd`, `level_cmd`, `temp_cmd` (у выключателя `cmd`, бывает `invert`).
Сервер панели подставляет их сам, в том числе для Sprut.hub.

Для камеры `snapshot` и необязательный `stream` — относительные адреса
wb-svg-panel, например `/cam/gate.jpg` и `/cam/gate.mjpeg?width=480&fps=5`.
Плитка запрашивает снимок раз в 1,5 с только на видимой странице. Полный экран
принимает MJPEG до 5 кадров/с (фактическая частота зависит от декодирования),
а при его отсутствии или ошибке использует снимки. «Назад» останавливает загрузку.
JPEG ограничен 512 КБ; два RGB565-буфера одного изображения занимают не более
около 900 КБ PSRAM, буферы скрытых страниц освобождаются.

## Первая прошивка по USB (один раз)

1. VS Code с расширением ESP-IDF, версия ESP-IDF 5.5.x.
2. Открыть папку проекта: File → Open Folder → `esp32-panel`.
3. В нижней строке: цель **esp32s3**, порт платы (COM3), способ прошивки **UART**.
4. Терминал ESP-IDF (Ctrl+E, T):
   ```
   idf.py set-target esp32s3
   idf.py -p COM3 erase-flash
   idf.py -p COM3 flash monitor
   ```
   `erase-flash` нужен только в первый раз — стирает остатки ESPHome.
   Первая сборка скачает LVGL с components.espressif.com в `managed_components/`.
5. На экране — «Настройка Wi-Fi». Подключите телефон к сети `Panel-XXXX`
   с паролем с экрана, выберите домашнюю сеть, сохраните.

Дальше USB не нужен.

## Выпуск новой версии

1. Поднять версию в `CMakeLists.txt` (`set(PROJECT_VER "0.1.1")`).
2. Собрать: `idf.py build`.
3. `python tools/release.py` — кладёт в `release/fw/` прошивку и `version.json`.
4. Скопировать оба файла на контроллер (команду печатает скрипт):
   ```
   scp release/fw/esp32-panel.bin release/fw/version.json root@192.168.1.77:/mnt/data/esp32-panel-fw/
   ```
5. Экраны обновятся сами в течение часа или сразу по кнопке
   «Проверить обновление».

### Раздача прошивок с контроллера

Один раз на WB: папка и правило nginx рядом с вашим `location /panel/`.

```
mkdir -p /mnt/data/esp32-panel-fw
```

```nginx
location /panel/fw/ {
    alias /mnt/data/esp32-panel-fw/;
    add_header Cache-Control no-store;
}
```

Затем `nginx -t && systemctl reload nginx`. Проверка:
`curl http://192.168.1.77/panel/fw/version.json`.

Адрес папки меняется на веб-странице экрана (поле «Папка с прошивками»).

## Устройство проекта

| Файл | Что делает |
|---|---|
| `main/board.h` | выводы и тайминги платы |
| `main/lcd.c` | инициализация ST7701S, RGB-панель, связка с LVGL, подсветка |
| `main/touch.c` | тач GT911 |
| `main/net.c` | Wi-Fi, точка доступа, DNS для страницы настройки, время |
| `main/web.c`, `main/web/index.html` | веб-страница экрана |
| `main/ota.c` | обновление с сервера и файлом, откат |
| `main/ui.c` | экраны |
| `main/tiles.c` | плитки из раскладки, заставка |
| `main/pads.c` | полноэкранные пульты и их вид на плитках |
| `main/charts.c` | графики в плитке и во весь экран |
| `main/camera.c`, `main/camera_mjpeg.c` | камеры, JPEG/MJPEG и полный экран |
| `main/history.c` | фоновая загрузка точек истории и лент «Сегодня» по HTTP |
| `main/mq.c` | MQTT |
| `main/layout.c`, `main/layout_default.json` | источники и хранение раскладки, забор с сервера, встроенная раскладка |
| `main/lv_mem_psram.c` | память LVGL в PSRAM |
| `main/settings.c` | настройки в NVS |
| `partitions.csv` | два слота по 6 МБ + 3,9 МБ под данные |
| `tools/release.py` | подготовка файлов для сервера |
| `dependencies.lock` | зафиксированные версии библиотек (обновляется сборкой, хранится в git) |
| `.clangd` | настройка подсказок редактора для ESP-IDF |

Шрифт — Inter (SIL OFL, `main/fonts/OFL-Inter.txt`), урезан до латиницы
и кириллицы, рисуется в любом размере через TinyTTF.
