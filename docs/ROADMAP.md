# План

## 0.2 — панель из JSON и MQTT

- Подключение к брокеру (адрес уже в настройках, `mqtt://192.168.1.77:1883`).
- Раскладка панели из JSON: встроенная по умолчанию и загружаемая через
  веб-страницу экрана (кнопки «Загрузить» и «Скачать текущую»). Хранится
  в разделе `storage`.
- Первые плитки: свет (вкл/выкл), диммер, сцена, датчик (температура, влажность).
  Типы и поля — как в `config.yaml` wb-svg-panel, чтобы JSON читался так же.
- Команды — напрямую в `…/on`, значения — подпиской на топики плиток.
- Обновление прошивки по команде в MQTT-топик.

Пример раскладки:

```json
{
  "version": 1,
  "pages": [
    { "title": "Гостиная",
      "tiles": [
        { "type": "dimmer", "title": "Подсветка", "w": 2,
          "state": "/devices/wb-led_122/controls/CCT1",
          "level": "/devices/wb-led_122/controls/CCT1 Brightness" },
        { "type": "scene", "title": "Вечер",
          "cmd": "/devices/lightingScenes/controls/evening/on" },
        { "type": "sensor", "title": "Столовая", "unit": "°C",
          "value": "/devices/wb-msw-v4_149/controls/Temperature" }
      ] }
  ]
}
```

## 0.3 — раскладка с сервера

- Эндпоинт в wb-svg-panel: JSON раскладки экрана из `config.yaml`.
- Порядок источников: загруженная вручную → с сервера → копия во flash → встроенная.
- Сигнал «раскладка изменилась» через MQTT, сверка по хешу.
- Плитки: кондиционер (колесо тонкими линиями), шторы, термостат, фанкойл.

## Разобраться

- **Строка цветных точек внизу экрана.** Была и на тестовой картинке ESPHome
  с той же инициализацией. Проверить тайминги кадра (vsync porch) и регистры
  развёртки ST7701S.
- **Оттенок фона.** Задан почти чёрный `#0E0F13`, на фото выглядит синеватым.
  Сверить вживую; при необходимости поправить гамму в инициализации матрицы.
- **Частота кадров.** Сейчас 12 МГц (~45 кадров/с), как в ESPHome. С bounce-буферами
  можно попробовать 14–16 МГц для более плавных анимаций.
